# TintLab
TintLab is a simple design token and code creator for rapid web and app prototyping.

[Version 1](https://simeonpaynter.github.io/TintLab/) released November 20th.
Key features include:
- A "Design token" generator (default tab 1) with a component preview
- Quickly source compiled css variables based on the "prefix" (ex. brand, base, system).
- A drag-drop wireframe component builder (tab 2) utilizing the design tokens for quick wireframe sketches.
- Once the wireframe looks good, you can "load to html" allowing for quick html, css, and javascript adjustments to bring to your favorite editor, agent, etc.
